# Volcano Gui

VolcanoEngine 的 2D 用户界面系统（静态库目标 `Gui` / `libVolcanoGui.a`），提供面向游戏 HUD 与交互界面的轻量级组件树、自动布局和事件派发机制。

## 主要特性

- **文档与组件树模型**：
  - `Document`：作为 UI 根容器与状态管理者，负责整棵界面的测量、排版与事件派发。
  - 父级所有权的树形结构：父组件负责子组件的生命周期与内存管理。
- **弹性盒自动布局（Layout）**：
  - 基于轻量级 Flexbox 布局模型，支持横向/纵向排列、弹性伸缩、外边距/内边距、对齐与自动换行。
- **核心控件集**：
  - 基础呈现：`Text`（文本）、`Image`（图像/九宫格）。
  - 交互控件：`Button`（按钮）、`CheckBox`（复选框）、`Slider`（滑动条）、`ProgressBar`（进度条）。
- **统一样式配置（Style）**：
  - 支持层级样式覆盖，统一定义字体尺寸、颜色、背景、边框半径与阴影状态。
- **平台解耦**：
  - 通过 `Platform` 接口抽象输入设备、光标状态与系统剪贴板，界面逻辑不直接依赖窗口库。
