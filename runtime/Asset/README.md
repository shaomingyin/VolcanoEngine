# Volcano Schema

VolcanoEngine 的资源模式与序列化库（静态库目标 `Schema` / `libVolcanoSchema.a`），负责引擎原生资源格式的数据定义、合法性校验以及二进制/JSON 流式序列化与反序列化。

## 资源格式

| 格式 | 文件扩展名 | 说明 |
|---|---|---|
| **Model** | `.vemodel` | 顶层模型定义，组合网格节点、材质引用与层级变换关系 |
| **Mesh** | `.vemesh` | 几何网格数据（顶点属性、索引缓冲、子网格划分与包围盒） |
| **Material** | `.vemat` | 材质着色属性、着色器配置及采样纹理映射 |
| **Texture** | `.vetex` | 纹理元数据与像素原始数据 |

## 主要特性

- **流式读写**：所有资源直接通过 `Base::Stream`（支持 `PhysFile` 文件流和 `Buffer` 内存流）进行序列化与反序列化。
- **数据校验**：在反序列化期间提供严格的边界和一致性检查，非法或损坏的数据将抛出明确异常。
- **不依赖渲染**：纯数据表达与解析，解耦具体图形后端，支持服务端与离线工具复用。
